# PerezLearn AI Workspace

Welcome to the **PerezLearn AI Workspace** GitHub organization. 

[Click here to visit our website - www.perezlearn.ai](https://perezlearn.ai)


PerezLearn AI Workspace is a practical learning environment designed to help learners gain **real-world work experience** through structured projects, professional workflows, AI-powered supervision, continuous feedback, and measurable skill development.

Instead of only learning concepts, learners are placed in simulated professional roles where they complete realistic projects, work through milestones and sprints, submit their work, receive reviews, make corrections, and build evidence of practical competency.

## What the AI Workspace Does

The PerezLearn AI Workspace helps learners:

- Work on realistic, industry-inspired projects
- Experience structured professional workflows
- Complete tasks through milestones and sprints
- Connect project work with tools such as GitHub
- Submit work for AI-powered review
- Receive actionable feedback from an AI Supervisor
- Improve submissions until requirements are satisfied
- Track progress and demonstrated competencies
- Build stronger portfolios based on practical evidence
- Develop workplace readiness alongside technical knowledge

## AI Supervisor

The **AI Supervisor** acts as an always-available project supervisor for learners.

It can help to:

1. Assign and explain project tasks
2. Review submitted work
3. Identify errors, gaps, and areas for improvement
4. Provide structured feedback
5. Track requested corrections
6. Re-review updated submissions
7. Measure progress against project requirements
8. Generate evidence of skills demonstrated during project execution

The goal is not to replace human instructors or mentors, but to reduce repetitive supervision and give learners continuous support between instructor interactions.

## GitHub Integration

For software engineering and related technical roles, GitHub is an important part of the workspace.

A typical workflow may look like:

```text
Project Assigned
      ↓
Milestone Created
      ↓
Sprint Tasks Assigned
      ↓
Learner Works on Repository
      ↓
Code Pushed to GitHub
      ↓
Submit for Review
      ↓
AI Supervisor Reviews Work
      ↓
Feedback Generated
      ↓
Learner Makes Corrections
      ↓
Re-review
      ↓
Task Completed
      ↓
Skill Evidence Recorded
```

This allows learners to practise workflows similar to those used in real software development environments.

## Important Notice

Projects provided through PerezLearn may use fictional, simulated, sandboxed, or educational data.

Learners should never upload:

- Employer confidential information
- Production credentials
- API secrets
- Customer personal information
- Proprietary source code without authorization
- Sensitive financial information
- Private organizational documents
